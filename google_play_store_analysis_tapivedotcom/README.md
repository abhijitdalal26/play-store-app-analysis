# Google Play Store Tapive Dataset Analysis

This directory contains the completed exploratory analysis for the **Tapive Google Play Apps and Games dataset**. The local dataset used for this notebook is about **1.1 GB** and contains **3,460,966 app records** with **36 columns**.

The notebook is built for large-file analysis: DuckDB reads the CSV efficiently, while `plot_helpers.py` keeps charting logic separate from the analytical flow.

## Dataset

Download the raw dataset from Kaggle:

[Google Play Apps and Games by Tapive](https://www.kaggle.com/datasets/tapive/google-play-apps-and-games)

Expected local path from this repository:

```text
../data/google-play-dataset-by-tapivedotcom.csv/google-play-dataset-by-tapivedotcom.csv
```

The `data/` directory is intentionally ignored by Git because the CSV is too large to commit.

## What This Analysis Covers

The Tapive dataset acts as the large historical baseline for the project. It is useful for understanding broad Play Store patterns that are harder to see in a smaller fresh scrape:

1. Data quality, schema, missing values, and duplicate checks
2. Rating, install, review, category, release-year, and IAP-price distributions
   - **2.7b** Year-over-year trends (2012–2023): new apps per year, avg score, avg installs, and monetization mix shift
3. Free vs paid performance and monetization model comparisons
4. Correlations between installs, reviews, ratings, app age, screenshots, and price
5. Outlier detection for suspicious ratings, weak viral apps, and poor pricing choices
6. Developer publishing patterns and quality differences
7. Business opportunity signals by category and monetization tier
8. Final takeaways for app-market strategy

## Key Findings

- The dataset contains **3.46M app records**, but roughly two-thirds have never received a rating (`score = 0`). The corrected average rating for apps that have been rated is approximately **4.1 stars**, not the raw 0.517 figure that appears if unrated apps are included in the average.
- Ratings cluster strongly between **4.0 and 4.8 stars**, so category-specific benchmarks are more useful than one global rating average.
- Apps with a perfect **5.0 score but very few ratings** should be treated carefully because they may reflect inflated or immature rating signals.
- Installs follow a strong **power-law distribution**: a small group of apps captures most downloads, while the long tail sits mostly around the 1K-50K install range.
- Free apps dominate the market. Paid apps generally receive far fewer installs, and paid apps above about `$20` often show weak demand.
- High-install apps commonly use **free + IAP**, **free + ads**, or hybrid monetization rather than paid-only models.
- Games dominate total app count and installs, while categories like Communication, Social, and Productivity often perform strongly on average installs.
- Reviews and ratings are the strongest install correlates in the notebook's log-scale analysis.
- Most developers publish only one or two apps. Very high-volume "factory" developers exist, but many show weaker average quality.
- The typical successful 10M+ install app profile is free or freemium, rated at least about 4.2 stars, has many reviews, is several years old, and usually includes 5-8 screenshots.
- **Year-over-year trends (2012–2023)** show that new app releases peaked around 2019–2020 and have declined since; IAP and ad-supported adoption has grown steadily over the same period while paid-app share has continued to shrink.

## How to Run

From inside this directory:

```powershell
jupyter lab google_play_store_kaggle_dataset_analysis.ipynb
```

The notebook expects the dataset at:

```text
../data/google-play-dataset-by-tapivedotcom.csv/google-play-dataset-by-tapivedotcom.csv
```

For Kaggle, change `DATA_PATH` in the setup cell to the Kaggle input path, for example:

```text
/kaggle/input/<your-dataset-slug>/google-play-dataset-by-tapivedotcom.csv
```

## Column Reference

| Column | Meaning |
|--------|---------|
| `appId` | Unique package name |
| `title` | App display name |
| `developer` / `developerId` | Developer name and numeric ID |
| `free` | 1 = free, 0 = paid |
| `price` | App price in USD |
| `offersIAP` | Whether the app offers in-app purchases |
| `minprice` / `maxprice` | IAP price range when available |
| `adSupported` | Whether the app shows ads |
| `genre` / `genreId` | Category name and ID |
| `score` | Rating from 0 to 5 |
| `ratings` | Total rating count |
| `reviews` | Total review count |
| `histogram1`-`histogram5` | Star breakdown from 1-star to 5-star votes |
| `minInstalls` | Install-count floor bucket |
| `releasedYear` / `releasedMonth` / `releasedDay` | Release date components |
| `ParseReleasedDayYear` | Parsed full release date |
| `dateUpdated` | Last update date string |
| `len screenshots` | Number of screenshots in the listing |
